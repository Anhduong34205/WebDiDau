\section{Kết quả triển khai}
Hệ thống đã triển khai các nhóm chức năng:
\begin{itemize}
    \item Khám phá, tìm kiếm, lọc, sắp xếp và xem tour.
    \item Giỏ đặt chỗ, gửi yêu cầu đặt tour và tra cứu đơn.
    \item Quản trị tour và đơn hàng bằng bearer token.
    \item Chatbot RAG sử dụng embedding, Vectorize và Workers AI.
    \item Triển khai toàn bộ frontend và API lên Cloudflare Workers.
\end{itemize}

Ứng dụng production được triển khai tại địa chỉ:

\begin{center}
\texttt{https://didau-travel.anhduong34205.workers.dev}
\end{center}

\section{Phương pháp kiểm thử}
Kế hoạch kiểm thử gồm các bước sau:
\begin{enumerate}
    \item Chạy typecheck cho workspace API và frontend.
    \item Build frontend bằng Vite.
    \item Smoke test endpoint `GET /api/tours`.
    \item Smoke test endpoint `POST /api/chat`.
    \item Kiểm thử guardrail ngân sách, tour trực tiếp và địa điểm không có trong catalog.
    \item Kiểm tra API quản trị bằng `ADMIN_TOKEN` mà không ghi secret vào báo cáo hoặc mã nguồn.
\end{enumerate}

\section{Các tình huống kiểm thử chatbot}
Các câu hỏi thử gồm:
\begin{itemize}
    \item ``Tour biển đảo dưới 3 triệu''.
    \item ``Tìm tour nghỉ dưỡng yên tĩnh cuối tuần''.
    \item Câu hỏi có tên tour cụ thể.
    \item Câu hỏi về địa điểm không xuất hiện trong catalog.
\end{itemize}

Tiêu chí đánh giá bao gồm:
\begin{itemize}
    \item HTTP 200 đối với request hợp lệ.
    \item `suggestedTourIds` trỏ tới tour active trong catalog.
    \item `suggestedTours` khớp danh sách `suggestedTourIds`.
    \item Tour gợi ý không vượt ngân sách đã trích xuất.
    \item Không đưa ra địa điểm, dịch vụ hoặc mức giá không có trong dữ liệu closed-world.
    \item Context đưa vào mô hình nằm trong giới hạn token.
\end{itemize}
